## 二、当场裁决（贵方 §5 的设计问题，逐条给结论与落点）

| # | 贵方问题 | ★ 裁决 | 落点 |
|---|---|---|---|
| ① | PROF-3 的「全分辨率」指什么（§5.1） | ★★★ **= 选定 profile 的【全部原生有效深度样本】，即 D2C 对齐/上采样【之前】的 640×400 帧**。🚫 不硬性要求改 1280×800（升档另按延迟/带宽评审，`19` PD-12）。快线需加原生分流（`19` §3.2A / W-3 已列改造点） | `11` PROF-3 v1.9 |
| ② | mask→depth 映射（§5.1 / Q-8） | ★★ **投影查表**：原生深度像素 3D 点经出厂 depth↔color 内外参投到彩色面取 mask，🚫 跨像面比例缩放。v1 不做遮挡 z-buffer —— 误查风险已声明并由 `FREE = T ∧ G` 的 G 侧兜住 | `19` §3.2 |
| ③ | T 通道取原始分割还是 `safe_traversable`（§5.4） | ★★ **取原始可通行类分割**。预扣语义障碍 = 双重融合；图像 5 px 腐蚀 ≠ 米制余量 —— 余量统一由 PROF-5 在地面域施加 | `11` v1.9 T 取材行 |
| ④ | 角度与量纲语义（§5.2 / Q-2 / Q-3） | ★★ `angle_min` = **第 0 bin 中心**，bin i 覆盖 `[中心±step/2)`；对称域要求 n 奇 且 `angle_min = −(n−1)/2·step`（贵方指出的 `[−45°, +45.5°)` 非对称写法弃用）。距离量纲：`d_free/d_block/range_max/blind_near` **一律 `base_link` 水平径向 `hypot(x,y)`** | `11` v1.9 约定表 |
| ⑤ | 地面不能恒 `z=0`（§5.3） | ★★★ 成立。**逐帧地面平面拟合**（外参先验做种子），`z_exp` 改逐帧闭式（每像素 ~8 flops）；拟合失败退先验平面 ＋ `degraded_reasons: ground_fit_fallback`。真实斜坡由 slope 停止条件管，🚫 套负障碍判据 | `19` §3.2A · `11` reason 登记 |
| ⑥ | 腐蚀缺旋转项（§5.4） | ★★ 成立。`m(r) = (v_ego_max ＋ ω_max·r)·Δt ＋ m_jitter`；无 odom 判角速度时**恒取 `ω_max`**（保守）。有同步位姿后可改重投影，只许更保守 | `11` PROF-5 v1.9 |
| ⑦ | 单组边界 ＋ src 是否自洽（§5.5） | ★★★ 取贵方给出的**第二种方案**：`profile` = 各通道归约后的**最近阻挡边界**，`src` 标注选中边界来源；S 通道分源信息的**完整载体是 `ObjectsMsg`**（逐目标距离可恢复），「融合留给 RNS」指**行为策略**融合。同批钉死三条：`d_block` 之后**恒 UNKNOWN**（遮挡）；`h_block` 是**可见表面高度下界**（只见局部会低估）；据此**本期 RNS 不启用跨越判定**，一律绕/停 | `11` v1.9 约定表 |
| ⑧ | `d_free = blind_near` 的语义（§5.2） | ★ 已明文：表示**已验证区间为空**，`(0, blind_near)` 恒 UNKNOWN，消费方不得读成"盲区可通行"（RNS 侧本就由记忆栅格＋RNS-I-6 管近场） | `11` `d_free` 行 v1.9 |
| ⑨ | 20 Hz 统计口径（§4） | ★★★ 冻结：**只计唯一、完整的新推理帧**（重发旧结果不计）；测点 = **发布端**；10 s 滑窗逐帧滑动；上电预热 30 s 不计；置位/清除各需持续 ≥10 s（迟滞）。★ 采纳贵方提议**新增 `infer_gap_ms_p99`** 字段防均值掩盖断供。RNS 接收端验收另在联调对表 | `11` §3.1B.3 v1.9 |

**关于 20 Hz 的路线约束**（贵方 §4）：三条硬约束（CPU 主机侧 / 双模型 DLA / 仅 fallback 走 GPU / 精度硬门不降 / 1080p 接口不变）**收到并尊重**。我方交接文档里"挪一个模型上 GPU"的提示**撤回**；"INT8 是现成余量"的说法**收回**（已获知 PTQ 试过且精度/漏检门失败）。**路线取舍归贵方**（我方 `19` PD-14 已如此登记），验收只认 `fps_infer` 与上款口径。
