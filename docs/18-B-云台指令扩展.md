## 2. `E09` 转速档位

| `level` | 触发说法 | 语义 |
|---|---|---|
| `slow` | 转速最慢 | 到最慢档 |
| `normal` | 恢复正常转速 | 默认档（开机初值） |
| `fast` | 转速最快 | 到最快档 |
| `up` | 转速加快 / 转速快一点 | 升一档；已在 `fast` ⇒ 保持 ＋ 复述「已经是最快」 |
| `down` | 转速减慢 / 转速慢一点 | 降一档；已在 `slow` ⇒ 保持 ＋ 复述「已经是最慢」 |

★★★ **说法必须带「转速」二字（2026-08-05 用户拍板）** —— 母本 `E01` 的 `large` 档触发词逐字含 **「快点转」**（语义是**转得多**）。
⇒ 「云台快点转」在只加「云台」前缀的方案下**仍不可判**（`E01` 示例说法本来就带云台前缀）。**消歧靠的是「转速」二字。**

★ 闭集档位而非 `0–100`：语音说不出百分比；且 **`T-PTZ-3`（`speed_pct` → 度/秒 标定曲线）未闭环**，具体数值今天无法验证。

⚠️ **两条须裁**：
① `E09` 只影响 `E01`/`E06`，🚫 不影响 `E03` 预置位与 `E07` 扫描（后者有自己的 `ptz.scan.speed_pct = 30`）。
② ★★★ 母本 §7.6 有一条「`pan`/`tilt` 速度随 zoom 升高**自动**下调」（`T-PTZ-7`），会与 `E09` 的**手动**档位打架。
**无论怎么裁，最终形式必须是 `v_eff = min(E09 档位, zoom 联动上限)`** —— 任何一侧只能降速，🚫 `E09` 的 `fast` 不得抬高上限。

## 3. ⚠️★★★ `E10` 与现行契约直接冲突

| # | 冲突源 | 逐字 |
|---|---|---|
| ★★★ ① | `11` §7.4「已删除字段（收到即拒）」 | `d_pan_deg` · `d_tilt_deg`（**角度增量**）→ `rejected` + `E_CAPABILITY`，`reason = "no_absolute_positioning"` |
| ★★★ ② | `18` §7.1（`99` C28.2#1） | 「**绝对定位在 PELCO-D 外置云台下是空操作 —— 返回成功但不动**」 |
| ★★★ ③ | `18` §7.1（`99` C28.2#2） | 「**位置回读恒为假值 `(180, 0)`**」⇒ **转完无法验证转了多少** |
| ⚠️ ④ | `18` §12 `T-PTZ-3` | `speed_pct` → 度/秒 **标定曲线未闭环** ⇒ 「转 N 度发多久脉冲」**今天算不出来** |

**唯一可行路径 —— 开环按时间估算**：`pulse_ms = N_deg / omega(speed_pct) × 1000`，而 `omega` 曲线就是 `T-PTZ-3`。
★★ 这与母本对 `E04` 的定性同类（「**开环增量跟随，会漂移**」）⇒ **`E10` 转出的角度是估算值，误差会累积。**

### 三条硬约束（无论怎么裁都不能松）

| # | 约束 |
|---|---|
| ★★★ 1 | **复述只能说「已按约 N 度发出转动命令」，🚫 绝不能说「已转 N 度」** —— 依据 `18` §7.3 逐字「只能答『已发出归位命令』，不得答『已归位』——我们没有任何手段验证结果」 |
| ★★★ 2 | 🚫 **`T-PTZ-3` 未闭环期间不得拿猜的 `omega` 先跑** —— 直接 `rejected` ＋ 引导用 `E01` 三档。依据母本 §7.2 禁令「不得偷偷折成某个档位」 |
| ★★★ 3 | 🚫 **估算角度不得写进 `state/mode.ptz` 当位置** —— 位置回读恒假，本系统**没有云台朝向真值** |

### `E10` 槽位

| 槽位 | 闭集 / 值域 |
|---|---|
| `direction` | **四值** `left` \| `right` \| `up` \| `down`。🚫 不含斜向 ——「左上转 30 度」的角度语义不可分解 |
| `angle_deg` | 左右 `(0, 360]` · 上下 `(0, 90]`（⚠️ 见 `Q-4`）。★ **必须正数**，方向由 `direction` 表达 |

## 4. `E06` 说法扩充（🚫 不新增意图，不影响 128 计数）

| 用户说法 | `direction` | `amount` |
|---|---|---|
| 拉近 / 放大 | `in` | `medium` |
| 近一点 / 大一点 | `in` | `small` |
| 拉远 / 缩小 | `out` | `medium` |
| 远一点 / 小一点 | `out` | `small` |

★★★ **必须写死的等价关系**：**「拉近」≡「放大」≡ `in`（视场变窄）** · **「拉远」≡「缩小」≡ `out`（视场变宽）**。
★ 依据 `11` §7.4 逐字 `zoom : + = 拉近（视场变窄）` —— 契约层只有一个 zoom 轴。⚠️ 但口语里是两个词，不写死等价关系模型会分类错。
