## 二、"独立有效依据"的构成（解除收窄的前提，`19` §3.2A v1.6）

```text
e(r) = |Δh| + r · tan(Δtilt) + e_align                    # 先验平面相对当前地面的高度误差界, 随距离增长
  Δh     = height_m(now) − calib.body_height_m             # 机身高度相对标定时的偏移(实测, 非假设)
  Δtilt  = IMU 重力向量相对标定时姿态的偏差                  # PD-18 定源(338Le IMU / 底盘 IMU)
  e_align= 安装 / 对齐 / 测量残余(固定上界, 安装实测填, 19 §8.2 fallback_align_err_m)

FREE 回退放行     ⇔ 三项齐全 ∧ 各自新鲜 ∧ e(dfree_cap_fallback_m) ≤ h_tol_m
几何阻挡保留      ⇔ 依据齐全 ∧ h_est(点) > h_tol_m + e(r)          # h_est 是算法估计, 🚫 用测试真值
任一项缺失 / 过期 / 键为 null  ⇒  整支收窄(= 贵方第二节表), 🚫 部分放行
```

| 依据项 | 来源接口 | 现状 | 谁定 |
|---|---|---|---|
| `Δh` | ★ `11` §9.8.2 `state/chassis_motion.height_m`（底盘 `Height`，10 Hz，**字段已存在**）＋ 标定层新键 `calib.body_height_m`（外参标定时的机身高度） | ★★ perception 的 `11` §1.1.6 白名单目前只订 `rt/gnss/fix` / `heading`；订 `state/chassis_motion` 须**新增白名单条目**（通用面）—— **PD-19，待负责人裁定** | 负责人 |
| `Δtilt` | PD-18（IMU 源）＋ 标定时姿态基准记录 | 待定（r4 已登记） | 贵方 + 负责人 |
| `e_align` | `19` §8.2 新键 `fallback_align_err_m`（`null` 拒启纪律不变） | 安装实测填 | 贵方 |

★ 贵方例（相机抬高 5 cm，12 cm 路沿剩 7 cm 落入 8 cm 容差）在此框架下的处置：有 `Δh = 0.05` 实测 ⇒ `e(1.5) ≥ 0.05 ＋ …` ⇒ `h_tol_eff(1.5) ≥ 0.13 > 0.12` ⇒ 路沿**不可判**（UNKNOWN，🚫 假 FREE）—— 与贵方"不能只检查误差小于容差、必须进分类"的要求一致：`e(r)` 进的是**分类阈值**，不是旁路检查。

★ 5 cm 是否在本机运动范围内：**不假设**。`Δh` 是实测量，范围由底盘 `height_m` 逐帧给出；安装/运行边界因此**不需要**作为验收前提写死——这正是用接口替代"边界声明"的理由。
