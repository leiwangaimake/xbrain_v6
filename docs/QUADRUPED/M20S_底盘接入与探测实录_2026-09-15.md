## 4. 本体监控协议（CHS-A）探测结果

### 4.1 端口与加密（定案 13 册 V-40）

| 探测 | 结果 |
|---|---|
| UDP `30000` 明文心跳（hex32 码 `0x00100064/0x00000005` 十进制序列化，及旧手册十进制 `100/100`） | **无响应** |
| TCP `30000` / `30001` | **关闭** |
| TCP `30002` | 开放，是 robot_server 的 **HTTP 服务**（日志 `http服务器启动，监听端口: 30002`；GET / 与 POST 未继续探） |
| TCP `30003` | **TLS 1.3**（`TLS_AES_256_GCM_SHA384`）。服务器证书 `CN=server.local, O=RobotServer, OU=Server`，签发链 `TLS CA ← Project CA`（C=CN, ST=Beijing），有效期 2026-04-03 ～ 2027-04-03，SAN 仅 `localhost` / `127.0.0.1`。握手后服务器发 `CertificateRequest`：无客户端证书 ⇒ 告警 **116 certificate required**；自签客户端证书 ⇒ 告警 **48 unknown CA** ⇒ 只认其 CA 签发的客户端证书 |
| UDP `30004` | **DTLS 1.2**，同样 `CertificateRequest`，无证书握手失败（告警 40） |
| TCP/UDP `40000` | robot_server 的 `TLS_STATUS` 查询服务（日志：`TLS_STATUS 响应数据: {"PatrolDevice":{"Command":1,"Items":{"SCE":1,"Version":"3.1.1"}...}`）；用 APDU 心跳格式试探无应答，请求格式未知 |

- `/opt/robot/fastdds.xml`（每台机器都有）的 `interfaceWhiteList` 与 `metatrafficUnicastLocatorList` 默认只有 `127.0.0.1`；`/opt/robot/scripts/setup_ros2.sh` 会按本机末段把 `10.21.33.103` / `10.21.31.104` / `10.21.33.106` 写进白名单（需 root 才能改该文件）。

- 在 GOS 上把 `/opt/robot/fastdds.xml` 拷到 `/tmp/fd_probe.xml`、白名单加上 `10.21.33.104` 后，`ros2 topic list --no-daemon` 看到全部跨主机话题（§5.2）。⇒ **外部主机只要把自己的网口写进 FastDDS 白名单就能直接订阅**，不是「不能外接」。
