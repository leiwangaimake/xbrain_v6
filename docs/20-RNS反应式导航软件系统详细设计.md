## 2. 导航语义

### 2.1 ★★★ 【新裁决 · `RNS-N-1`】点到点与路径统一为**折线跟随**

| 项 | 内容 |
|---|---|
| 裁什么 | ★ 点到点导航 ＝ **只有一段的折线**；路径导航 ＝ **稠密折线**。两者用同一套跟随逻辑，🚫 不写两条代码路径 |
| 依据 | ★ 用户 2026-09-07：「路径导航其实是多个点到点导航的串行执行」；★ 录制路径 **0.5 m 一个点**（`11` §12A.6 / `99` U42 的录制去重下限） |
| ★ 为什么不能做成「逐点到达再转向」 | ★★★ 0.5 m 一个点 ⇒ 一条 2.5 km 的路径有 5000 个点，每个都停下转向**在物理上不可接受**。用户 2026-09-07 逐字：「如果每个都停下转向那太夸张了」 |
| ★ 失效方向 | ★ 统一后只有一处逻辑，🚫 不会出现「单点导航修好了而路径导航没修」 |
| ★★★ **推翻它需要什么证据** | ★ 出现一类路径，其相邻点间距**大到**折线跟随退化为直线导航（例如稀疏航点巡逻）。★ 即便如此，折线跟随在单段上**就是**直线导航，无需另写 |

### 2.2 ★★★ 折线跟随的三个量

```text
  折线 P[0..n]（RTK/SLAM 定位点序列，WGS84 → 局部 ENU）
  机器人当前位置 X

  ① 最近点：在【索引窗口】内求 X 到折线的最近点 F，记其段索引 i 与段内参数 t
  ② 横向偏差：e = |X − F|                      ← 偏离判定 · 限速
  ③ 前视点：  R = 沿折线从 F 前移弧长 L 所达的点  ← ★ 一切方向决策的基准
              L = clamp(k_lookahead · v, L_min, L_max)
```

★★★ **`R` 是本册所有方向决策的唯一基准** —— §6 的候选打分、§7 的贴墙退出，全部以「朝 `R`」为参照，🚫 不以原始首末点连线为参照。理由见 §2.3。

### 2.3 ★★★ 【新裁决 · `RNS-N-2`】绕行后的重入**不做成独立状态**

| 项 | 内容 |
|---|---|
| 裁什么 | ★ 🚫 不设「绕行模式 / 返回模式」两态。绕开后回到折线，靠**目标方向 `X→R` 自然指回**实现 |
| 为什么 | ★★ 做成两态就要回答「什么时候算绕完了」「返回途中又遇障怎么办」，而这两个边界没有非任意的定义方式<br>★★★ 用 `R` 作基准后三种情形自动统一：<br>· 在线上无障碍 ⇒ `X→R` ≈ 折线方向 ⇒ 直行<br>· 在线上有障碍 ⇒ 按 §6 选候选<br>· **偏离后** ⇒ `X→R` **斜指回折线** ⇒ 打分自然偏好「能回线」的候选 |
| ★ 前视距 `L` 的物理含义 | ★★ 它是**回归强度**的旋钮：`L` 小则贴线紧、回归急，但高速下会绕线画 S 形（纯追踪的经典失稳）；`L` 大则回归平缓但偏离持续更久 |
| ★ 失效方向 | ★ 无模式 ⇒ 无模式切换抖动 |
| ★★★ **推翻它需要什么证据** | ★ 实测出现「靠 `X→R` 无法收敛回折线」的几何（例如大偏离 + 小 `L` 下的极限环）。★ 那时正确的动作是**改 `L` 的自适应律**，🚫 不是加一个返回模式 |

### 2.4 ★★ 中间点与终点的语义不同

| | 中间点 `P[i]`（i < n） | 终点 `P[n]` |
|---|---|---|
| 作用 | ★ **路径形状** —— 只用于定位 `F` 与 `R` | ★ **导航目标** |
| 到达判定 | 🚫 **不做** | ✅ `dist(X, P[n]) < arrival_radius` |
| 航向要求 | 🚫 无 | ✅ 见 §2.5 |

⚠️ **把 `arrival_radius` 用在中间点上是一个具体的错误**：航点半径量级为米，而点距 0.5 m ⇒ 一次「到达」会跳过数个点，路径形状被破坏。

### 2.5 ★★★ 【新裁决 · `RNS-N-3`】到点航向用**渐进对准**，🚫 不原地补转

| 项 | 内容 |
|---|---|
| 裁什么 | ★ 剩余距离 `d < align_dist_m` 时进入**对准段**：期望航向从「沿路径方向」平滑插值到目标航向，边走边转 |
| 依据 | ★ 用户 2026-09-07：「不是走到后原地旋转，而是最后剩余距离情况下的逐步调整」；`align_dist_m` 默认 **5 m**、可配 |
| ★★★ **可行性约束（必须写进实现）** | ★ 所需角速度 `ω_req = Δθ · v / d`。★★ 若 `ω_req > wz_max` ⇒ **必须降速**，🚫 不得超速转 —— 否则到点时角度没转够，只能原地补转，正是本条要消除的现象<br>⇒ 等价形式：`align_dist_m ≥ Δθ · v / wz_max`，不满足则压 `v` |
| ★ M20S 的便利 | ★ 平台可同时出 `vx / vy / wz` ⇒ 对准段可**边平移边转**，用 `vy` 补偿转向引起的横向偏差，落点与航向同时到位 |
| ★ 目标航向从哪来 | ★ `waypoints.yaw_deg`（非空则必须对准）；`docks` 恒需对准（独立字段 `dock_heading_rad`） |
| ★★★ **推翻它需要什么证据** | ★ 实测证明在 `align_dist_m` 内平台无法同时满足位置与航向精度（例如低速下 `wz` 分辨率不足）。★ 那时的正确动作是**加大 `align_dist_m`**，🚫 不是退回原地补转 |
| ★★ **控制律（v1.11 量化）** | ★ 期望航向插值：`θ_des = θ_path ⊕ w(d)·wrap(ψ_goal − θ_path)`，`w(d) = clamp(1 − d/align_dist_m, 0, 1)`（线性权重，d 为剩余弧长）；★ 角速度 `ω = clamp(k_yaw · wrap(θ_des − ψ), ±wz_max)`（P 律，与 `12` §4.4 同族）；★ 压速上限 `v ≤ align_eta · d · wz_max / max(|Δθ|, 1e-3)`（本行就是左侧可行性约束的实现式，`align_eta < 1` 为余量系数） |
| ★★★ **到达判定（v1.11 量化）** | ★★★ **双条件同时**：`d ≤ arrival_radius_m` **且** `|wrap(ψ_goal − ψ)| ≤ yaw_tol_deg`（有目标航向时）。🚫 只判半径 —— 那会在航向未对准时报到达，正是本条要消除的现象（断言 A-ALN-3）。★ FLOAT 档半径放大：`arrival_radius × arrival_radius_float_scale`（§3.2.1） |

### 2.6 ★★ 【新裁决 · `RNS-N-4`】索引窗口 + 单调不回退

| 项 | 内容 |
|---|---|

### 2.11 ★★★ 【新裁决 · `RNS-N-17`】第三级导航：waypoint → waypoint 的全局层（v1.8 · 用户 2026-09-08 确认；v1.9 展开为完整数学）

#### 2.11.1 三级模型（执行内核唯一，`RNS-N-1` 不破）

```text
L1  goto(p)          折线 = [x_now, p]                      （两点退化折线）
L2  path(P)          折线 = 录制的 [p_1 .. p_n]（点距 Δ = 0.5 m）
L3  wp2wp(x -> W_b)  折线 = 全局层在【路网图】上算出, 交 L2 执行
```

★★★ **全局知识已经存在**：录制路径 ＋ waypoints 就是路网 —— L3 🚫 不是让局部避障硬闯未知地形，是在已录的路上认路。
★ 这正是 `RNS-M-6` 推翻条款预设的姿势：**规划器产出折线交给 RNS**，RNS 仍是唯一速度源，零架构冲突。
★ 统一进度坐标：折线 `P : [0, L] → R²` 按弧长参数化；`s_k = arg min_{s ∈ 窗口} ‖x_k − P(s)‖`（`RNS-N-4` 单调窗口投影）。本册一切收敛论证建立在 `s` 上（理由见 §7.3 v1.8 改写注）。

#### 2.11.2 ★★ 图构造（数学定义处；实现归 `p3_task`，#20-14）

**输入**：路径集 `{R_j}`，每条是弧长参数化折线 `R_j : [0, L_j] → R²`，采样点距 `Δ = 0.5 m`（`11` §12A.6 录制去重下限）；waypoint 集 `{W_m}`。

**汇合点（junction）判定**：

```text
点对 (p ∈ R_a, q ∈ R_b), a ≠ b, ‖p − q‖ ≤ d_join  =>  合并为同一节点（并查集）
实现: 空间哈希, 格宽 d_join, 只查相邻 9 格 => 建图 O(Σ n_j)
```

★★ **引理 NET-L1（`d_join` 的下界，防漏交叉）**：两条采样折线横截相交于点 c，各自最近采样点距 c 的弧长 ≤ `Δ/2`（段内任意位置的最坏是中点）。交点处四个射线对的夹角为 `θ, π−θ, θ, π−θ`，取**锐角那一对**（`min(θ, π−θ) ≤ π/2`）上的两个采样点：距离 ≤ `2·(Δ/2)·sin(π/4) = Δ/√2 ≈ 0.354 m`。
⇒ **`d_join ≥ Δ/√2` 保证真实交叉不漏检**。★ 代价：间距 < `d_join` 的两条平行路径会被并为同一走廊 —— 语义上可接受（0.35 m 内的"两条路"本就是一条）。

**图**：`G = (V, E)`；`V = {W_m} ∪ {每条 R_j 两端点} ∪ {汇合点}`；`E` = 同一条 route 上相邻节点间的**子折线**，权 `w(e) =` 该段弧长。

#### 2.11.3 ★★ 查询：A* 与最优性

```text
plan(x_now -> W_b):
  ① 接入   p_in  = argmin_{p ∈ 全部采样点} ‖x_now − p‖ ,  d_in = 该最小值
           p_out = W_b 的挂点（waypoint 录制时即在路上, d_out ≈ 0）
  ② 搜索   A*:  f(v) = g(v) + h(v),  g = 累计弧长,  h(v) = ‖v − W_b‖
  ③ 拼接   P = [x_now → p_in] ⊕ 路网子折线(g 最优路) ⊕ [p_out → W_b]
  ④ 执行   经 cmd/motion/route（P1-11 既有通道）交 RNS；接入/末段就是 L1 —— 三级在此闭合
```

★★ **引理 NET-L2（h 可采纳且一致 ⇒ A* 免重开最优 [6][7]）**：边权 = 弧长 ≥ 弦长 `‖u − v‖`（三角不等式逐段），而 `|h(u) − h(v)| ≤ ‖u − v‖ ≤ w(u,v)` ⇒ `h` 一致（consistent）⇒ A* 每节点至多扩展一次即得最短路。复杂度 `O(|E| log |V|)`，`|V|` 是稀疏节点集（waypoints ＋ 端点 ＋ 汇合点），🚫 不是全部 0.5 m 采样点。

★ **同 route 特例**：`a, b` 同在 `R_j` 上 ⇒ 子折线直取；环形 route 取较短弧：`min( s_b − s_a , L_j − (s_b − s_a) )`（模 `L_j`）。

★ **拼接连续性**：路网段相邻点距 ≤ Δ；接入/末段是直线段，由 RNS 前视机制消化 —— 输出折线无需再平滑（`RNS-N-3` 渐进对准管末端航向）。

#### 2.11.4 ★ 退化情形（用户 2026-09-08 裁决）

| 情形 | 策略 |
|---|---|
| ★★★ `d_in > d_attach_max`（脱网）或图不连通 | ★★★ **裁决 (a)**：`‖x_now − W_b‖ ≤ goto_direct_max_m` ⇒ **回退纯 L1 直线 goto**（收敛仍由 §7A 定理罩住）；否则任务侧拒绝，原因 `no_route`（🚫 RNS 侧失败 —— 规划失败发生在执行之前） |

| ★★★ 为什么不是投票 | ★★★ 「两票表决」把两条**覆盖面不同**的证据当成同一件事的两次独立观测。★ 按票数合并时，未标注物体（只有几何一票）会被判为「证据不足 ⇒ 通行」 |
| ★★★ **推翻它需要什么证据** | ★ 实测证明某一通道在**全部**场景下都是另一通道的超集。★ 若成立，正确的动作是**去掉冗余通道**，🚫 不是改成投票 |

★ 落到报文上：`src[θ]` 位掩码就是「谁说的」，**融合前必须保留**，否则上式的并/交无从判断（`11` §3.1B.1）。

#### 3.1.3 ★★★ 两个通道**同时失效**的场景

★★★ 上面的并集规则**救不了**这一类：玻璃 · 水面 · 强反光 · 超量程 · 投射器阴影。
★ 这些地方**深度成片 invalid（几何什么都没有）**，而语义也最容易把水面误判成铺装路面 —— **两边都说「没有障碍」**。

⇒ ★★★ **只能靠第三态兜住**：

| 不变量 | 内容 |
|---|---|
| ★★★ **`RNS-I-1`** | ★★★ **深度 invalid 必须保持 `UNKNOWN` 语义，🚫 不得在任何环节被隐式转成 `far` 或 `free`**（🚫 不得填 0，🚫 不得填最大量程）<br>★ 生产侧对应 `11` §3.1B 的 **PROF-2**；**两条都要**：PROF-2 管 perception 不许发假值，`RNS-I-1` 管 RNS 收到 `null` 后不许自己填 |
| ★★★ **`RNS-I-2`** | ★ `invalid_pixel_ratio`（`11` §3.1B.3 `StatusMsg`）超阈值 ⇒ **强制限速**（§8.1）。这是唯一覆盖「两通道同时瞎」的手段 |

⚠️ **`RNS-I-1` 是本册最容易被实现者顺手抹掉的一条** —— 填个默认值代码更简单，且现象上「跑得更顺」。
★ 它同时是 `CLAUDE.md` §3.1「未标定就报 `null`，🚫 不得伪造 0.0」在感知面的实例。

#### 3.1.4 ★★★ 融合策略**留在 RNS**，perception 只做逐通道降维

| 项 | 内容 |
|---|---|
| 裁什么 | ★ perception **各通道分别**逐点降维并**保留来源归属**（`src` 位掩码）；🚫 不在 perception 内融合成单一结论 |
| 为什么 | ★★★ 语义通道的主要价值**不是冗余检测，是行为差异**：<br>· `person` ⇒ **停车礼让，不绕**<br>· `block`（设备/箱体）⇒ 绕行<br>· `traverse`（浅草/落叶）⇒ 可穿越，限速<br>· `hazard`（明火/深水/崖边）⇒ **硬禁止 ＋ 额外膨胀**<br>★★ 融合成「堵/通」后这四种全部塌缩成「堵」，**花了语义的算力只拿到几何的信息量** |

#### 3.1.5 ★★★ 语义目标：RNS 为什么要这几个字段

> ★ 字段表见 `11` §3.1B.2 `ObjectsMsg`。★★★ 本表是**用途与做错的后果** —— 接口评审时对着它逐条问「这个字段是怎么算出来的」。

| 字段 | RNS 拿它做什么 | ⚠️ 缺失/做错的后果 |
|---|---|---|
| ★★★ `track_id` | **判运动状态的前提** | ★★ ID 一跳变，`stable_frames` 归零 ⇒ **永远得不出「这车停了 3 秒」** |

| `confidence` · `semantic_status` | 低置信度、代理类按保守处置 | ★ `proxy` 当 `confirmed` 用 ⇒ 把「像是消防栓」当成确认的硬禁止物 |

#### 3.1.6 ★★★ 几何三态：`d_free` 与 `d_block` 之间那条带

| 不变量 | 内容 |
|---|---|
| ★★★ **`RNS-I-3`** | ★★★ **`d_free ≤ d_block` 恒成立。** 两者之间那条带**就是** `UNKNOWN`（遮挡 / 无深度 / 未确认地形）<br>🚫 **绝不能令 `d_free = d_block` 把它消掉** —— 那等于宣称「没看见障碍 ＝ 那里没障碍」<br>★ 生产侧对应 `11` §3.1B 的 **PROF-1** |

#### 3.1.7 ★★ 负障碍（独立标记）

★ 坑 / 崖 / 台阶下沿的特征是「射线**没有**按预期命中地面」—— 在体素里表现为**该方向地面消失**，而不是「有障碍」。
⚠️ 必须与「深度 invalid」**可区分**：前者是「确认那里没有地面」，后者是「不知道」。
★ 两者都不可通行，但前者是 `BLOCKED`（`src` 置负障碍位、`h_block` 取负）、后者是 `UNKNOWN`（`d_block = null`），**对速度策略的影响不同**：前者绕行，后者限速探行。

##### ★★ 分辨率专题：**按用途分路，🚫 不统一降采样**

★ 提高深度分辨率的**算量不是瓶颈** —— 深度图是 organized 二维数组，反投影 ＋ 变换 ＋ 地面判定 ＋ 角度归约合计约 20–30 flops/点，1280×800@30fps 约 1 Gflops/s；★★ 且双模型跑在 **DLA0/DLA1**，GPU 基本空闲。

★★★ **真正的风险是带宽与延迟**：1280×800×16 bit×30 fps 约 492 Mbps，加 Color 流后千兆链路占用过半；而 **F-1 的延迟已经超标**，提分辨率的第一风险是把它推得更高。

⇒ **按用途分路**：

| 路径 | 分辨率 | ★ 理由 |
|---|---|---|
| ★★★ **安全 / 几何剖面** | ★★ **全分辨率** | ★★★ 角度域 **MIN 归约本身即降维**；MIN 保守 ⇒ **细障碍只要 1 个有效像素就存活**（`11` §3.1B.1 **PROF-3**） |
| 地面拟合 / 聚类 | 可降采样 | ★ 本质是求平均，降采样无损，省算力 |
| 分割 / 检测 | 模型输入尺寸 | 受模型限制 |

⚠️★★★ **顺序不可换**：**先降采样再归约，第一步就把细障碍平均掉了** —— 矿区钢筋 · 树林细枝 · 营地拉索正是「最容易漏 ＋ 撞上后果最严重」的一类。

## 4. 三态空间表征

### 4.1 ★★★ 三态强制

> ★★★ **空间中每一处必须被明确标记为 `FREE` / `BLOCKED` / `UNKNOWN` 之一。**
> ★★★ **`UNKNOWN` 永远不等于 `FREE`。**

| 状态 | 允许 |
|---|---|
| `FREE` | ✅ 允许进入 |
| `UNKNOWN` | ⚠️ **限速进入**（🚫 不禁止 —— 全禁则近场盲区会让机器人寸步难行） |
| `BLOCKED` | 🚫 硬禁止 |

★★ 这一条同时解决四类问题：**FOV 盲区**（盲区 = UNKNOWN，天然限速）· **漏检**（未确认 ≠ FREE）· **未标注物体**（几何 BLOCKED）· **非结构化地形**（可通行分割直接给 FREE，不需枚举草叶石块）。

### 4.2 ★★ 局部三态栅格（记忆）

| 项 | 内容 |
|---|---|
| 锚定 | ★★★ **锚在定位系（RTK/ENU），🚫 不锚在机体系** |
| 为什么 | ★★★ 这是本平台有 RTK 的**最大红利**：绝大多数机器人的局部地图靠里程计补偿，误差累积让记忆只能维持 1~2 秒。★ 有厘米级绝对位姿 ＋ 绝对航向后，**记忆时长由环境变化速率决定，不由传感器精度决定**；★★ 且**原地转身完全不破坏地图** |
| 每格内容 | `state`（三态）· `class`（若来自语义）· `t_seen`（单调钟） |
| ★★ TTL 分档 | ★★★ **静止障碍 TTL 长，动态障碍 TTL 短**<br>⚠️ 动态障碍记太久 ⇒ 留下**幽灵障碍**堵住通路，而现场看不到任何东西 |

#### 4.2.1 ★★ 写入与失效规则（v1.11 量化 —— 初版只有语义无规则）

| 规则 | 内容 |
|---|---|
| 栅格参数 | `memory.cell_m` × 半径 `memory.radius_m`（机体为中心的滑动窗，格心世界系对齐防抖动）；两键 `null` 待整定 |
| ★ 写入面 | **只写本拍观测扇区内的格**（视野外的格一律不动 —— 这就是「记忆」的来源） |
| ★★★ 覆盖规则 | ★★★ `BLOCKED`/`FREE` 覆盖任何旧值并刷新 `t_seen`；**观测到的 `UNKNOWN` 🚫 不覆盖非 UNKNOWN 旧值** —— 否则遮挡/invalid 每拍都会把身后刚看清的记忆抹掉，贴墙（§7.4）立刻失效 |
| ★ class 冲突 | ★★ **v1.16 改（用户 2026-09-09 裁决）**：同格新旧 class 不同 ⇒ **最新观测的 class 覆盖**（本次写入带 class 即以它为准；本次无 class 则保留旧值），随 `t_seen` 一并更新。★ 理由：TTL 按合并后 class 选档（动态短/静态长），若按旧规则「取更危险者」，一个**未过期**的静态 class（hazard）会粘在后来的动态障碍（person）上 ⇒ 该格拿静态长 TTL ⇒ 人走开后幽灵墙滞留 —— 三轮审查实测出的坑。「cell 现在被什么占着」由**最新一次带 class 的观测**说了算，危险度合并不是 TTL 语义的正确输入。⌦ 旧规则（取更危险者）作废 |
| ★ 失效 | `t_now − t_seen > ttl_{class}` ⇒ 该格回 `UNKNOWN`（TTL 分档见上表） |
| ★★★ 锚定重置 | ★★★ 单拍位姿跳变 `‖Δpose‖ > memory.reset_jump_m`（RTK 修复/重收敛）⇒ **整栅格清为 UNKNOWN ＋ `warn`** —— 跳变后旧记忆整体错位，错位的 BLOCKED 是假墙、错位的 FREE 是假通路，**清空是唯一保守解**（断言 A-MEM-3） |

★★ **贴墙绕行（§7）结构上依赖本节** —— 见 §7.4。

### 5.2 ★★★ `person` 恒停，🚫 不绕不穿

> ★ **唯一例外**：`follow_target` 的**指定 `track_id`**（§2.10.2 —— 豁免只在行为分流层且保距，🚫 不豁免几何安全层，🚫 不按 class 扩散）。

| 项 | 内容 |
|---|---|
| 裁什么 | ★★★ `person` **一律停车礼让**，🚫 不进入穿绕候选，🚫 不按测速分流 |
| ★ 为什么不按运动状态分 | ★★★ 同一个人可能触发两种**完全相反**的行为（站着 ⇒ 绕过去 / 走动 ⇒ 停下等），而两者之间**没有非任意的边界**。★★ 判别在两态间抖动 ⇒ 机器人一会儿要绕一会儿要停，动作表现为「犹豫」，**而在人身边犹豫比任何一种确定行为都危险**<br>★★ 更反直觉的后果：**判成「静止」反而更危险** —— 「静止 ⇒ 绕过去」意味着贴着人走；那人恰好在贴近时动了，就撞上了 |
| ★ 失效方向 | ★ 恒停 ⇒ 最坏是等待，人会自己让开 |
| ★★★ **推翻它需要什么证据** | ★ 出现「人不会让开且必须绕」的确定场景（例如躺卧的伤员）。★★ 那时正确的动作是**新增一个语义类**并给它独立的余量与限速，🚫 不是让 `person` 整类可绕 |

### 5.3 ★★★ 动态障碍的距离规则

| 动态障碍占住所选走廊 且 `r_near > stop_dist_m` | ★ 减速 |
| 动态障碍占住所选走廊 且 `r_near < stop_dist_m` | ★★ **停止** |

| 项 | 内容 |
|---|---|
| ★★★ **停止与恢复必须是两个阈值** | ⚠️ 单阈值在门限附近 ＋ 测距噪声 ⇒ **走走停停**。`resume_dist_m > stop_dist_m` |
| ★ `stop_dist_m` 默认 | **3 m**，可配（用户 2026-09-07 指定） |

### 5.3A ★★ 【新裁决 · `RNS-N-16`】停等预算（v1.8 · 用户 2026-09-08 确认；v1.9 展开）

**状态与判据**（形式化 §5.3 的停/恢复）：

```text
Blocked(t) := ∃ 动态障碍 o: 占住所选走廊(o, RNS-N-8) ∧ r_near(o) < stop_dist_m
停等状态:   Blocked 为真且因此 v_cmd = 0
计时:       τ_wait += Δt   当且仅当处于停等状态

超时:       τ_wait > wait_budget_s => 上报失败 blocked_by_dynamic{track_id, class_name}

```

| 规则 | 内容 |
|---|---|
| ★★★ **计时绑【状态】不绑 track** | ⚠️ 绑 track 的写法有对抗性反例：**轮换堵门**（A 走 B 来）每次换人就重置计时 ⇒ 预算永不触发。⇒ 只要停等状态**连续**为真就累计，换了谁在堵不影响计时；上报时才取当前最近者 |
| ★ 静止重分类联动 | 障碍通过 §5.5 判据（`|v| < v_static ∧ 驻留 t_dwell`）⇒ 移入静止堆 ⇒ 穿/绕候选**自然可用**，停等自行解除（Blocked 变假）。🚫 `person` 恒停不重分类 |
| ★ `person` 堵路 | 超时上报带 `class = person`；**喊话/驱离联动归上层**（用户裁定：本册只上报，留钩子不设计） |

### 5.4 ★★★ 【新裁决 · `RNS-N-8`】「占住我要走的路」的定义

### 5.5 ★★★ 静止判据 ＝ 速度阈值 ＋ 驻留时间

## 6. 候选生成与选择

### 6.1 ★★★ 【新裁决 · `RNS-N-9`】穿插与绕行是**同一个算法**

> ★★★ 两者都是「**剖面不连续点 → 外推安全半径 → 得子目标 → 统一打分**」。
> 🚫 实现上不设「这是绕还是穿」的分支 —— 图上的行为差异由**打分自然产生**。

| 情形 | 边缘来源 | 子目标 |
|---|---|---|
| **绕行**（单障碍） | 障碍的**外缘切点** `E` | `S = E + clear · n̂`（`n̂` ＝ 背离障碍的法向） |
| **穿插**（双障碍之间） | 两障碍的**相邻内缘** `E₁ / E₂` | `M = (E₁+E₂)/2`，`S = M + clear · û`（`û` ＝ 机器人指向 `M` 的方向） |

| 项 | 内容 |
|---|---|
| ★★★ **必须外推** | ⚠️ 绕行：直接把切点当目标 ⇒ **擦着墙角过去**<br>⚠️ 穿插：瞄准门中点 ⇒ 到达即完成 ⇒ **机器人停在门里** |
| ★ 什么是「边缘」 | ★ 沿方位角扫剖面，`d_block(θ)` 发生**跳变**处（一侧 1.5 m 有东西、隔壁畅通到 8 m）即障碍在该视角下的切点 |
| ★★★ 边缘不可见时**没有子目标** | ★★ 墙延伸出 FOV 时那一侧算不出子目标 —— **这不是缺陷，是诚实**：你确实不知道那边绕多远<br>⇒ ★ 先由记忆栅格补；记忆也没有 ⇒ 该候选记为**代价未知**，仅在无任何已知候选时启用，并用**目标点所在侧**做启发式偏置 |

★ **`clear` 的定义（v1.11 量化）**：`clear = r_eff ＋ margin_by_class(该边缘障碍类) ＋ candidate.subgoal_extra_m`（末项 `null` 待整定）—— 🚫 不是独立魔数，前两项与 §6.2 硬门 ① 同源。

### 6.2 ★★★ 硬门（任一不满足 ⇒ 该候选**排除**，不参与打分）

```text
  ② 动态目标的膨胀足迹与 P→S 走廊相交              （§5.4）
  ③ P→S 走廊穿越 allow 围栏外 / hazard             （§3.3）
  ④ S 落在【无观测且无记忆】的区域                  （§4.3 RNS-I-6）
```

★★★ **本节没有时间维度** —— ①③④ 是静态几何，② 是当前时刻的相交测试。

### 6.3 ★★★ 【新裁决 · `RNS-N-10`】宽度做**硬门 ＋ 饱和**，🚫 不做线性优先

| 项 | 内容 |

### 7.3 ★★★ 【新裁决 · `RNS-N-12`】退出判据（三条同时成立）

### 7A.1 模型 · 前提 · 设计约束

**模型**：工作空间 `W ⊂ R²` 有界；障碍 `O_1..O_N` 紧致、边界逐段光滑；机器人半径折进膨胀：
自由空间 `F = W \ ∪_i (O_i ⊕ B(r_eff))`，此后按**点机器人**论证 [1][8]（膨胀后相互接触的障碍并作一个连通分量，个数仍有限）。
折线 `P : [0, L] → W`；进度 `s` 与 `s*` 如 §2.11.1 / §7.3A 定义。

| # | 前提 / 约束 | 内容 |
|---|---|---|
| **A1** | 静态 | 环境静态；膨胀后每个障碍连通分量边界周长 ≤ Λ |
| **A2** | 定位 | 误差 ≤ ε_loc，且 `e_ok_m > 2·ε_loc`、`δ_s > 2·ε_loc`（判定门限可分辨；`δ_s = leave_progress_m`） |
| **A3** | 感知 | 所贴边界在感知＋记忆栅格保鲜期内连续可测 |
| **A4** | 可达 | 目标与起点在 `F` 同一连通分量（不成立时见结论第 2 支） |
| ★ **A5**（v1.9 补） | 横截性 | 折线与各膨胀障碍边界**横截相交且交点有限**（一般位置假设，标准处理 [8]）。记折线与全部障碍边界的交点对总数为 `K` |
| **D1**（设计约束） | 贴墙速度下界 | `d_wall_m` 落在速度门非零段 ⇒ 贴墙走行速度 ≥ v_min > 0 |

### 7A.2 定理与时间上界

**定理（RNS-T-1）**：在 A1~A3 ＋ D1/D2 下，算法（折线跟随 ＋ 穿/绕 ＋ 看门狗 `RNS-N-15` ＋ 贴墙 ②' ＋ §7.6）在有限时间内**恰好**进入两种终态之一：
**① 到达**（A4 成立时必然）；**② 上报失败且原因正确**（A4 不成立 ⇒ §7.6-① 绕界一整圈触发；A3 局部失效 ⇒ `watchdog_no_progress`，见 §7.3A 分支二）。

**时间上界**（v1.9 精化 —— 反应层段数 ≤ 贴墙次数 ＋ 1，各段 ≤ 无进展上限）：

```text
N_wf ≤ L/δ_s + K                                  （贴墙次数: ②' 正常离墙 + D3 放宽离墙, 引理 L3）
T ≤ ( L/δ_w + N_wf + 1 ) · T_w                    （反应层: 打转上界 + 段数开销）
  + N_wf · Λ / v_min                              （贴墙总时长, 引理 L2）
  + L / v_follow                                  （正常行进）
  + T_task                                        （停等的外层上界 = 任务层超时, 见 7A.4）
```

### 7A.3 四条引理与证明

**L1（反应层有界）**：反应层任一连续无升级段耗时 ≤ `T_w · ⌈进展量/δ_w⌉` 意义下有界 —— 由 §7.3A：`τ_p` 只在反应层非停等时累计，达 `T_w` 未积累 `δ_w` 进度即强制升级（有墙 ⇒ 贴墙；无墙 ⇒ 终态②）。∎

**L2（单次贴墙有界）**：贴墙沿单一连通边界单向行走（§7 控制律），弧长 ≤ Λ（A1），速度 ≥ v_min（D1），离墙测试逐拍求值（A2 保证 ①/②' 判定可靠，A3 保证边界不丢）⇒ 至多 `Λ/v_min` 时间内：要么某点满足 ①②'③ 离墙，要么回到 H（A2 使 §7.6-① 的 ε 球判定可靠）触发失败。§7.6-③ 里程预算兜传感异常。∎

**L3（贴墙次数有界）**：正常离墙满足 ②'（每次 `s` 增 ≥ δ_s）⇒ 此类 ≤ `L/δ_s` 次；D3 放宽离墙每次至少消费一个折线-边界交点对且 `s` 严格增 ⇒ 此类 ≤ `K` 次（A5）。合计 `N_wf ≤ L/δ_s ＋ K`。
★★★ 本引理**只在 ②' 的弧长度量下成立** —— 欧氏版在弯曲路径上 `d_goal` 非单调，序列论证失效（v1.8 改度量的根本原因）。∎

**L4（失败正确性 ＋ 无假失败）**：设贴墙绕行障碍分量 `Ω`。
(i) **若 A4 成立且折线尾段可达**：折线在 `s_hit` 处进入 `Ω`，必在某 `s_exit > s_hit` 处穿出；沿 `∂Ω` 单向行走必经过穿出点（边界连通）。该点 ① 在折线上 ✓、③ 越过后通畅 ✓；②' 分两种：穿过障碍主体 ⇒ 增益 ≥ `2·r_eff > δ_s`（**D2**）⇒ 当场合法离墙；**擦边**（增益 ≤ δ_s）⇒ ②' 否决，但穿出点入 D3 记录 ⇒ 整圈时按 **D3** 在最大增益穿出点放宽离墙。两种情形都 **🚫 不会误报**。
(ii) **若绕完整圈回到 H 且 D3 记录为空**：⇒ 折线在 `(s_hit, L]` 段与 `∂Ω` 无任何穿出交点 ⇒ 目标与机器人被 `∂Ω` 分隔在不同连通分量 ⇒ 报「不可达」**正确**（保守感知语义下）。证法同 Bug2 的 M-line 论证 [1]，把直线 M-line 推广为弧长参数化折线。∎

**定理证明**：L1~L3 给出各模式时长与次数上界 ⇒ 总时间有界（7A.2 式）；有界时间内未到达 ⇒ 必然停在某失败分支（§7.6 / §7.3A-二 / §5.3A），L4 与各分支语义给出原因正确性。∎

### 8.1A ★★ 定性限速项的统一形状（v1.11 量化 —— 初版六项只有方向无公式）

★ 统一用**系数族** `g(x) ∈ [g_min, 1]`（`Factor` 类型，CFG-CM-18），乘任务标称速度得绝对上限进 §8.1 的 min：

```text
v_nom  = 任务标称: path 取 routes.max_speed, goto 取 patrol 档值      (静态, 每任务一次)
g↓(x; x0, x1, g_min) = 1            x <= x0          # 自变量越大越危险
                     = g_min        x >= x1
                     = 线性插值      其间
g↑ 同形反向 (自变量越大越安全)
cap_item = g_item · v_nom
```

| 项 | 自变量 x | 形状 | 键（`speed:` 段，全 `null`） |
|---|---|---|---|
| 横向偏差 | `\|e\|` | `g↓(x; dev_e0_m, max_deviation_m, dev_g_min)` —— x1 **复用** `route.max_deviation_m`，到界即 §2.7 失败 | `dev_e0_m` · `dev_g_min` |
| 穿缝紧度 | `ρ = w / (2·(r_eff＋margin))` | `g↑(ρ; 1, gate_saturate_ratio, gap_g_min)` —— 饱和点**复用** §6.3 键，宽过饱和即不限 | `gap_g_min` |
| UNKNOWN 占比 | 前向扇区（与 `f()` 同扇区）UNKNOWN bin 比例 | `g↓(x; unk_r0, unk_r1, unk_g_min)` | `unk_r0` · `unk_r1` · `unk_g_min` |
| 对准段 | —（绝对式） | `cap = align_eta · d · wz_max / max(\|Δθ\|, 1e-3)`（§2.5 控制律行） | `align_eta` |
| 贴墙 | —（常数帽） | `cap = wall_follow.v_max_mps`（既有键） | — |
| RTK FLOAT | —（常数系数） | `cap = rtk_float_g · v_nom`（§3.2.1） | `rtk_float_g` |

★ 单调性是这族公式的**可测性质**：每项 cap 对其自变量单调（hypothesis 属性测试，断言 **A-SPD-3**）。
🚫 形状之外不加平滑/迟滞 —— 抖动由输入侧（感知计龄、栅格、迟滞键）治理，两处都做会互相打架。

### 8.2 ★★★ 航向降级时的能力收缩

| 航向状态 | RNS 的能力 |
|---|---|
| `heading_valid == false` 或 `level == L2` | ★★★ **🚫 原地转向无意义**（`yaw_capable == false`）<br>★★★ **🚫 横移不可用** —— 横移方向由航向定义，航向不准 ＝ **往未知方向平移**<br>⇒ ★ 退化为「只沿运动方向直行 ＋ 大半径转弯」 |
