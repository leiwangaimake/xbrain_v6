## 1. 设备总览

| 规格项 | 参数 |
|---|---|
| 型号 | GZH-2 |
| 供电电压 | 24V |
| 峰值功率 | ≤80W |
| 通信接口 | 网口（以太网） |
| 控制方式 | 「智慧负载」APP（≥ 4.5.5） |
| 工作温度 | -20℃ ~ 45℃ |
| 控制距离 | 与链路设备距离一致 |
| 扬声器 | 110dBA@1m，15W |
| 音频功能 | 实时喊话、收音、音频播放、文字转语音；文件格式 Mp3/Wav/Flac/AAC |
| 收音麦 | 8 咪头阵列，收音距离 5m |
| 照明灯 | 30W，矩阵灯珠，泛光 |
| 红蓝灯 | 2 组，总功率 ≤15W，16 种模式 |
| 设备尺寸 | 不含快拆和防滚架 153.7×150×111；含快拆和防滚架 195.6×179×147（mm，长×宽×高） |

## 3. 通用约定

- **数值进制**：本文 `0x` 前缀为十六进制，其余为十进制。
- **音频编码**：Opus。喊话下行 采样率 8000 / 单声道 / 帧大小 480；收音上行 采样率 16000 / 单声道 / 每帧解码后 ≤320 字节（20ms）。
- **8529 灯光协议**：多字节数值均为单字节字段，无字节序问题；`len` 仅统计 **payload 字节数**。
- `⚠️` **8519 命令号的字节表示**：原文用方括号十进制写作 `[14]`、`[10]`…`[99]`。尚未确认设备端是把命令号当作**十进制单字节**（如 `[14]` → `0x0E`）还是其它编码。**接入前务必抓包/对照 SDK 确认**。本文命令表按原文十进制列出。
- `⚠️` **8519 的 TCP 分帧**：原文未描述长度前缀或结束符。推断为「一条命令 = 一次写入 / 一个 TCP 段」，粘包/拆包处理方式待确认。

| `[13]` | 停止播放录音 | — | |
| `[15]${text}` | 文字转语音 | `text`：UTF-8 | |
| `[16]${text}` | TTS 循环播放 | `text`：UTF-8 | |
| `[17]` | 停止 TTS 循环 | — | |
| `[31]${voice}${text}` | TTS V2（男女声） | `voice`：1 字节(0男/1女)；`text`：UTF-8 | |
| `[32]${voice}${text}` | TTS V2 循环（男女声） | 同上 | |
| `[18]` | 播放警报 | — | |
| `[19]` | 停止警报 | — | |
| `[40]` | 开始收音（下发） | — | |
| `[40]${音频}` | 收音数据（上行） | 前 4 位为 `[40]`，其后为 Opus 音频 | 需解码为 PCM 播放；16k/单声道 |

## 6. 俯仰控制（TCP 12345）

**帧**：`8D <俯仰值>`（2 字节）。

- 第 1 字节固定 `0x8D`；第 2 字节为俯仰值，**无符号整数 80–220**。
- 例：`8D 5A`（0x5A=90）。
- APP 换算：`⚠️` 进度条 0–100 → 实际下发 100–200（与灯光文档"备注"一致；与本文 80–220 范围略有出入，**以真机为准**）。

## 7. 灯光 / 警示 / 抛投钩协议（TCP 8529）

### 7.1 帧结构

```
+------+-------+--------+--------------+-------+
| 0x8D |  len  | MSG_ID | payload[len] | CRC8  |
+------+-------+--------+--------------+-------+
  包头   长度     命令号     负载(len字节)   校验
```

- `len` = **payload 字节数**（不含包头/命令号/CRC）。
- 控制类命令设备**不回复**（`不回复`，`✅`）。
- 设备的上报/回复报文同样采用本结构 `8D | len | ID | payload | CRC8`（对应原表"回复报文"列）。

### 7.2 控制命令表（`✅`）

| MSG_ID | 功能 | len | payload | 取值 |
|---|---|---|---|---|
| `0x01` | 控制开关灯 | 0x01 | `[0/1]` | 0关 / 1开 |
| `0x02` | 调节灯亮度 | 0x01 | `[0-30]` | 0–30（0 时灯不亮） |
| `0x03` | 控制爆闪开关 | 0x01 | `[0/1]` | 0关 / 1开 |
| `0x04` | 抛投钩控制 | 0x02 | `[钩号][开关]` | 钩号 0全部/1一号/2二号；开关 0关/1开 |
| `0x07` | 设置红蓝灯模式 | 0x01 | `[0x00-0x10]` | 16 种模式 |
| `0x25` | 状态上报（上行，500ms） | 0x18 | 见 §7.4 | — |

### 7.3 CRC8 校验（`✅ 已推导验证`）

原文只写「CRC8 校验」，未给多项式。经 5 个示例帧反推确认为 **CRC-8/MAXIM（Dallas / 1-Wire）**：

| 参数 | 值 |
|---|---|
| 多项式 poly | `0x31`（反射形式 `0x8C`） |
| 初始值 init | `0x00` |
| 输入反射 refin | 是 |
| 输出反射 refout | 是 |
| 输出异或 xorout | `0x00` |
| **校验范围** | `len + MSG_ID + payload`（**不含包头 0x8D**） |

**参考实现（Python，已通过全部示例）**：

```python
def crc8_maxim(data: bytes) -> int:
    """CRC-8/MAXIM，入参为 len+MSG_ID+payload（0x8D 之后的字节）。"""
    crc = 0x00
    for b in data:
        crc ^= b
        for _ in range(8):
            crc = (crc >> 1) ^ 0x8C if (crc & 1) else (crc >> 1)
    return crc & 0xFF

def build_frame(msg_id: int, payload: bytes) -> bytes:
    body = bytes([len(payload), msg_id]) + payload
    return b"\x8D" + body + bytes([crc8_maxim(body)])
```

**原文校验对照**（`✅` 全部吻合）：
`8D 01 01 01 → 0x31`(开灯)、`8D 01 01 00 → 0x6F`(关灯)、`8D 01 02 07 → 0xB9`(亮度)、`8D 01 03 01 → 0xA0`(开爆闪)、`8D 01 07 02 → 0x79`(红蓝模式2)。

### 7.4 状态上报 `0x25`（500ms 周期，上行）

**帧**：`8D 18 25 <24 字节 payload> <CRC8>`（`len=0x18=24`）。

payload 已知字段（`✅` 含义 / `⚠️` 具体字节偏移待确认，原表多为"保留"）：

- **探照灯**：状态与亮度，位定义 `B7=开关 / B6=爆闪 / B0-B5=亮度`。
- **红蓝警示灯**：总状态 `0=关 / 1=开`。
- 其余字节：保留。
