## 0. 本册是什么

### 0.1 ★★★ 本册【不是】把欠账关掉

实测项只有真去测才能关。本册**一条也没关**。

本册做的是另一件事：**让每一条欠账都有一个确定的、fail-safe 且 fail-loud 的默认行为，使它不阻塞编码。**

| 🚫 本册**不做**的 | 理由 |
|---|---|
| 🚫 给未标定量填一个「能跑起来」的数 | 那是 `CLAUDE.md` §3.1 的 fail-silent：`0.0` 会被判为「已赋值」而放行，机器人不动且无任何报错 |
| 🚫 分配任何新编号 | 分配者是 `99`（`M` / `U` 全类，`D` / `V` 段界）与段主册（`11` / `13`）。本册**只引用不新建**，见 `99` **NUM-1 / NUM-2** |
| 🚫 改写任何条目的语义 | 语义定义处在各册原位。本册第二列是**判据**，不是重新定义 |
| 🚫 重述阻塞性判定 | 「阻塞编码 / 阻塞验收 / 只是取值」的判定在 `99` §V 与 §M。本册不做第二份 |
