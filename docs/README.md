### V5 已查证的既成事实（[99](99-决策记录.md) C01–C11）

- zenoh：单 router 星型 `tcp/0.0.0.0:7447`，参与者 `connect 127.0.0.1:7447`，逐个显式关 multicast（★ 未关 gossip —— V6 必须关）
- ROS 2 **Humble** · `rmw_cyclonedds_cpp` · `ROS_DOMAIN_ID=42`
- ⚠️ **V5 的** ASR `POST /v1/asr/once` · TTS `POST /v1/tts/once`（ZipVoice）—— ★ **V6 不继承**：
  V6 的 ASR 是 `POST /v1/audio/transcriptions`（18081，CPU ONNX int8）；
  ★★ **2026-08-03 选型实测后默认模型改为 `paraformer-zh-2023-09`**（638 条按 `18` 合成的指令语料上 exact 53.1% / CER 22.7%，
  原 `zipformer-multi-zh-hans` 为 40.1% / 30.5%；RTF 0.050@4线程 · 0.118@1线程，需求界 0.5）。
  ★ **代价是热词失效** —— sherpa-onnx 只在 transducer 族支持解码期偏置，paraformer 没有。实测热词在词表完整时也只值约 **1 分**，
