# SEC-12 变异体夹具 —— 每条违规都必须被抓到

本文件**不是设计文档**，不进扫描面 manifest。它存在的唯一目的：给 `SEC-12` 的三项检查各提供一个
**必然违规**的样本。`sec12_scan.py --self-test` 扫本文件，**必须报出下面每一条**；漏报任意一条即为检查失效。

依据 CLAUDE.md §3.3：验收一条断言的唯一方式是注入一个必然违反它的变异体，看它变红。只写正例的断言等于没写。

★ 本文件内**禁止出现任何行级豁免标记**（`SP-8 豁免` / `EC-2 豁免` / `UL-6 豁免`），
也禁止出现会被判为「说明句」的词（判据 / 订正 / 墓碑 / 原文 / 历史 …）——
否则变异体会被豁免掉，检查又变成永远绿。
